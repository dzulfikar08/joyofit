**Apa:** Rutinitas latihan beban bisa dibagikan sebagai teks (gerakan, set, repetisi, beban, istirahat) ke WhatsApp atau Threads, atau diekspor sebagai file. File itu bisa diimpor lagi lewat "Impor rutinitas" di halaman Latihan beban, per rutinitas atau satu folder sekaligus.

**Kenapa orang peduli:** Program dari pelatih atau teman bisa dipakai tanpa mengetik ulang, dan rutinitasmu bisa dipindah ke HP lain. Gerakan buatan sendiri ikut terbawa, dan rutinitas yang sudah ada tidak pernah ditimpa.

**Angle post:** "Program push-pull-legs dari temanmu? Kirim filenya, impor di JoyoFit, langsung bisa dipakai."

**Bukti visual:** Buka satu rutinitas, ketuk Bagikan (screenshot teks di WhatsApp), lalu Ekspor file dan impor di HP kedua; screenshot pratinjau impor.

**Jangan klaim:** Belum ada di build yang dipegang pengguna (kode saja). File diimpor lewat tombol Impor rutinitas; membuka file langsung dari aplikasi lain belum bisa.
