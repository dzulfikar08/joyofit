**Apa:** Di layar latihan, kartu Ekspor menyimpan latihan sebagai file .fit (dan file GPX kalau latihannya punya rute) ke folder di HP, tanpa internet. Di Android kamu memilih folder sekali (JoyoFit mengingatnya, bisa diganti), di iPhone lewat "Simpan ke Files". Tombol "Upload di strava.com" membuka halaman upload Strava di browser, dengan petunjuk memakai mode Situs desktop lalu memilih file dari Unduhan. "Bagikan" tetap ada untuk Drive, WhatsApp, atau kirim ke laptop.

**Kenapa orang peduli:** Aplikasi Strava dan Garmin Connect tidak menerima file lewat menu Bagikan. Sekarang jelas caranya: simpan file, lalu upload dari situs webnya.

**Angle post:** Latihan dari jam Huawei ke Strava tanpa akun perantara: simpan file .fit di JoyoFit, upload di strava.com.

**Bukti visual:** Rekam layar detail latihan, ketuk "Simpan file .fit", pilih folder, lalu halaman upload Strava di browser dengan Situs desktop (data demo).

**Jangan klaim:** Ini upload manual lewat situs Strava, bukan integrasi resmi dan bukan fitur Strava; jangan pakai logo Strava atau Garmin. Hanya jam Watch Fit 4 Pro yang teruji. Android 11 ke atas tidak mengizinkan memilih folder Unduhan itu sendiri, jadi orang membuat atau memilih folder di dalamnya (belum dicoba di perangkat). Belum tersedia untuk pengguna sampai update OTA dipublikasikan. Jangan tulis 'tersedia di Play Store/App Store'.
