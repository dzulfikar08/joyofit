**Apa:** Halaman Masukan di JoyoFit Web (app.fit.joyorogo.com/issues), masuk dengan akun JoyoFit, tanpa daftar akun lain atau kode email: lapor masalah, bertanya, atau usul ide lewat formulir di halaman itu (bisa melampirkan tangkapan layar dan file .fit latihan), pantau status laporan dan balasan tim lalu membalasnya, dukung dan komentari ide orang lain, dan lihat ide yang sudah jadi. Terbuka untuk semua akun, tidak hanya Pro.

**Kenapa orang peduli:** Selama ini laporan tercecer di komentar Threads dan DM, tanpa berkas dan tanpa kabar lanjut. Sekarang laporan jadi tiket dengan email sendiri, lengkap dengan file .fit latihan yang bermasalah, dan ide bisa dilihat serta didukung orang lain.

**Angle post:** "Ada yang aneh di datamu? Buka fit.joyorogo.com/issues, lampirkan file .fit latihannya, lalu pantau balasan tim di halaman yang sama. Pakai akun JoyoFit-mu, tanpa daftar lagi."

**Bukti visual:** halaman /issues: formulir Laporkan masalah dengan file .fit terlampir, tab Laporanku dengan percakapan tiket (tim dan "Kamu"), tab Ide dengan tombol dukung, di HP dan desktop.

**Jangan klaim:** belum ada di aplikasi ponsel (hanya web; menu dan fitur lain JoyoFit Web tetap Pro); komentar ide tampil tanpa nama; nama status masih bahasa Inggris (Backlog, In Progress, Done).
